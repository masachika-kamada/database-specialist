# 独立性レベル (隔離性レベル / 分離性レベル)

Serializable: 直列化可能、参照しただけでロックがかかり他のトランザクションから「追加・削除」「更新」ができなくなる

Repeatable Read: 反復読み出し可能、参照しただけでロックがかかり他のトランザクションから「更新」ができなくなる、ファントムリード (今まで存在していなかった行がいきなり追加される) が発生する可能性がある

Read Committed: 他のトランザクションがコミットした場合、そのデータは自分のトランザクションでも読み取れる、ファジーリード (ある値がいきなり変わる、ノンリピータブルリードともいう) が発生する可能性がある

Read Uncommitted: 他のトランザクションがコミットしていなくてもそのデータは自分のトランザクションでも読み取れる、ダーティリード (未コミットのデータを読み取る) が発生する可能性がある

| 隔離性レベル    | 他のトランザクションでできること | ダーティリード | ファジーリード | ファントムリード|
|-----------------|----------------------------------|----------------|----------------|-----------------|
| Serializable    | ない                             |                |                |                 |
| Repeatable Read | 追加・削除                       |                |                | ◯              |
| Read Committed  | 追加・削除・更新                 |                | ◯             | ◯              |
| Read Uncommitted| 追加・削除・更新                 | ◯             | ◯             | ◯              |

```
postgres=> SELECT current_setting('transaction_isolation');
 current_setting
-----------------
```
