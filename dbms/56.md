# 直列化可能性 / 2 相ロック

* 直列化可能性: 並列実行した結果と直列実行した結果が同じになること。直列化可能なら、一貫性が保証される。
* 2 相ロック (2 相ロッキングプロトコル): 直列化可能性を保証するためのロック方式。トランザクションが必要になったときにロックをかける。トランザクションの最後にロックをかけたテーブル全てのロックを解除する (最後まで解除しない)。

初期値
* a = 1
* b = 2

| T1 | T2 |
|----|----|
| READ a | READ a |
| LOCK a | LOCK a |
| LOCK b | LOCK b |
| a = a + 3 | a = a + 3 |
| WRITE a | WRITE a |
| READ b | READ b |
| b = b + 5 | b = b + 5 |
| WRITE b | WRITE b |
| UNLOCK a | UNLOCK a |
| UNLOCK b | UNLOCK b |

上記のようなトランザクションの組み合わせでは、並列か直列かによって結果が変わる。
T2 が a の値を READ するタイミングが T1 と同時だったら 1 になるし、T1 の実行後だったら 4 になる。
直列化可能性を保障するためには、トランザクション内でデータへのアクセスの前にロックを書けることが必要。
