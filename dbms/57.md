# デッドロック

複数のトランザクションが互いに次に必要なリソースをロックし、アンロックの待ち状態に陥ること

| 時刻 | トランザクションA | トランザクションB |
|------|------------------|------------------|
| 1    | LOCK a           | LOCK b           |
| 2    | WRITE a          | WRITE b          |
| 3    | LOCK b           | LOCK a           |

2 相ロックでは、トランザクションの終了までロックを保持するため、上記のようなデッドロックが発生する可能性がある。
