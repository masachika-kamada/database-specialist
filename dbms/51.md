# コミットとロールバック

* トランザクション: 一連の複数処理をまとめたもの
* コミット: トランザクションの処理を確定する
* ロールバック: トランザクションの処理を取り消して、トランザクション開始前の状態に戻す

## 実行環境作成

* 複数のトランザクション実行のため、PostgreSQL の `psql` コマンドを使用
* VSCode の拡張機能で実行する SQL ファイルは、一回の実行によりトランザクションが終了するため、今回のように複数のトランザクションのタイミングが関係するものは実行できない

## 実行手順

1. PostgreSQL をインストール
2. C:\Program Files\PostgreSQL\17\bin にパスを通す
3. 2 つのターミナルから以下のコマンドでそれぞれトランザクションを起動<br>`psql -h mkamada-pgserver.postgres.database.azure.com -U mkamada -d postgres -p 5432`

## タイムライン (コミット)

| 時刻 | トランザクション1 | トランザクション2 |
|------|-------------------|-------------------|
| T1   | `SELECT 氏名 FROM 販売管理.会員 WHERE 会員コード = 102;`<br>➡ 骨川スネ夫 | - |
| T2   | `START TRANSACTION;` | - |
| T3   | `UPDATE 販売管理.会員 SET 氏名 = 'のび のび太' WHERE 会員コード = 102;` | - |
| T4   | `SELECT 氏名 FROM 販売管理.会員 WHERE 会員コード = 102;` | - |
| T5   | - | `SELECT 氏名 FROM 販売管理.会員 WHERE 会員コード = 102;`<br>➡ 骨川スネ夫 |
| T6   | `COMMIT;` | - |
| T7   | - | `SELECT 氏名 FROM 販売管理.会員 WHERE 会員コード = 102;`<br>➡ のび のび太 |

## ロールバック

```text
postgres=> start transaction;
START TRANSACTION
postgres=*> update 販売管理.会員 set 氏名 = 'ドラえもん' where 会員コード = 102;
UPDATE 1
postgres=*> select 氏名 from 販売管理.会員 where 会員コード = 102;
    氏名    
------------
 ドラえもん
(1 行)

postgres=*> rollback;
ROLLBACK
postgres=> select 氏名 from 販売管理.会員 where 会員コード = 102;
    氏名
-------------
 のび のび太
(1 行)

```
